# تقرير المشروع: تحليل APK وإعادة بنائه

> هذا التقرير يفصل بين ما **نُفّذ واختُبر فعلاً** وما **كُتب ولم يُختبر** وما **لم يُنفَّذ**.

## 1. تحليل الملف المرفق

* الملف: APK لتطبيق `org.hamak.mangareader` الإصدار 2.0.7.6.11 (رمز 276)، 23.7 MB، SHA-256 `7cf3be41…fbb0f6`.
* هو **الحزمة الأساسية فقط** (`requiredSplitTypes=base__abi,base__density`)، ولا تحتوي على مكتبات native، فلن يُثبَّت منفرداً على الأرجح.
* خمسة ملفات DEX (~13 ألف كلاس) مشوّشة بـ R8. فُكّت بـ jadx 1.5.1 مع 72 كلاس فاشل.
* البنية: Kotlin + Koin + Room + OkHttp + jsoup + Glide + WorkManager + kotlinx.serialization. طبقة `providers` (226 ملفاً) قوالب لأنظمة مواقع شائعة (Madara، Zeist…).
* ميزة المصادر اليدوية موجودة أصلاً: محددات (`path/attr/regex/replace`) + إعدادات للقوائم والتفاصيل والصفحات + قالب رابط (HTML أو JSON). الاكتشاف التلقائي فيها يستعين بدالة سحابية.
* خدمات خاصة بالمطور (Appwrite، `hamakpro.org`، Firebase، Play Billing، Unity Ads) وحماية `pairip` للترخيص.

**لم أنسخ أي شيفرة مفككة.** كُتب المشروع من الصفر، بعد فهم السلوك فقط.

## 2. ما نُفّذ

| المتطلب | الحالة |
|---|---|
| إضافة أي موقع عبر الرابط، مع تعديل/حذف/تعطيل وحفظ محلي | مكتوب (تطبيق) + **منطق الاكتشاف والحفظ مُختبر** (محرك) |
| اكتشاف بنية الموقع تلقائياً ثم التحقق الكامل | **مُختبر** على مواقع محلية |
| HTML وJSON وAJAX (POST) وبيانات داخل سكربت | **مُختبر** |
| JavaScript (وضع WebView) | مكتوب، **غير مُختبر** |
| موائم مستقل لكل موقع (إعداد JSON كامل لكل مصدر) + قوالب Madara/MangaStream | **مُختبر** (القوالب على مواقع محلية بتصميمها، لا على مواقع حقيقية) |
| كل الفصول: ترقيم، next-link، حارس حلقات لا نهائية، إزالة التكرار، ترتيب | **مُختبر** (120 فصلاً على 3 صفحات) |
| صور الصفحات الحقيقية فقط (lazy، srcset، سكربت، استبعاد الإيموجي/الأفاتار/الإعلانات) | **مُختبر** |
| التحقق من أن الملف صورة فعلاً (magic bytes) | **مُختبر** |
| آخر التحديثات مرتبة بالوقت الحقيقي + تحديث يدوي + سحب + تمرير لا نهائي | المنطق **مُختبر**؛ الواجهة مكتوبة فقط |
| تخزين مؤقت للعمل دون اتصال مع وسم «بيانات مخزّنة» ووقت آخر نجاح | مكتوب، **غير مُختبر** |
| عزل الأعطال (مصدر لا يعطّل غيره) ورسائل تشخيص بالعربية | **مُختبر** (المحرك) |
| الصلاحيات: إنترنت، حالة الشبكة، إشعارات (وقت التشغيل + مسار الإعدادات)، خدمة مقدمة للتنزيل | مكتوب، **غير مُختبر** |
| تنزيل الفصول (WorkManager، تحقق من كل صورة، علامة اكتمال) | مكتوب، **غير مُختبر** |
| قارئ عمودي مع الفصل التالي/السابق وإعادة محاولة الصفحة | مكتوب، **غير مُختبر** |
| متصفح مدمج تُشارَك كوكيزه مع طبقة الشبكة (للتحقق/الدخول يدوياً) | مكتوب، **غير مُختبر** |

## 3. الاختبارات التي نُفّذت فعلاً

`scripts/run-engine-tests.sh`: **62 اختباراً، نجحت كلها**، مرّتين: على jsoup 1.24-SNAPSHOT وعلى jsoup 1.17.2 (الإصدار الذي يستخدمه التطبيق).
كل «موقع» خادم HTTP حقيقي على localhost، فتعمل الشبكة وإعادة المحاولة والتحليل فعلاً. المجموعات:

1. وحدات: JSON، التواريخ (إنجليزي/عربي، نسبية)، أرقام الفصول، فحص الصور.
2. **إضافة موقع جديد غير معروف بالرابط فقط** → اكتشاف + تحقق كامل، تصفح بترقيم، بحث، تفاصيل، 30 فصلاً، 12 صفحة صحيحة بالترتيب، وإبعاد الإيموجي/الأفاتار/الإعلان/الشعار/التذييل، ورفض HTML محفوظ بامتداد صورة.
3. ترقيم الفصول: 120 فصلاً، تكرار محذوف، ترتيب مقلوب يُصحَّح، وموقع يتجاهل رقم الصفحة لا يسبب حلقة.
4. مصدر JSON معرّف يدوياً، مع الترتيب بوقت التحديث الحقيقي.
5. قوالب Madara (AJAX POST) وMangaStream (صور داخل سكربت).
6. أعطال: 503 مع 3 محاولات، صفحة حماية ضد الروبوتات (تُسمّى ولا تُتجاوز ولا تُعاد)، 403، محدد خاطئ، عنوان غير قابل للوصول، ومصدر سليم وسط 3 مصادر معطلة.

## 4. ما لم يُختبر (وهو الأهم أن تعرفه)

* **لم أبنِ التطبيق ولم أشغّله.** بيئتي بلا Android SDK، والمواقع `dl.google.com` و`maven.google.com` وMaven Central غير قابلة للوصول. لذلك كود `app/` **لم يُجمَّع ولو مرة**، وقد يحتوي أخطاء بناء. **لا يوجد APK.**
* **لم يُختبر أي موقع مانجا حقيقي.** الصدفة لا تصل إليها. نجاح الاختبارات على مواقع تجريبية لا يضمن النجاح على كل موقع حقيقي؛ المواقع المعتمدة على JavaScript الثقيل أو الحماية أو الدخول قد تحتاج ضبطاً يدوياً أو WebView.
* لم تُقارَن نتائج الاستخراج «بالموقع نفسه» لأن ذلك يتطلب موقعاً حقيقياً.
* قوالب Madara وMangaStream مكتوبة من معرفتي بتصميمهما ولم أتحقق منها على مواقع حقيقية؛ يتحقق منها الاكتشاف عند الإضافة.
* لم تُختبر الصلاحيات وقت التشغيل ولا الإشعارات ولا التنزيل في الخلفية ولا WebView.

## 5. القيود والمكونات المطلوبة

* **غير مُعاد عمداً:** حسابات Appwrite والمزامنة السحابية، الاشتراكات (Play Billing)، الإعلانات (Unity)، الإشعارات السحابية (FCM)، وحماية `pairip`.
* **غير مُنفَّذ:** المكتبة/المفضلة والسجل والتصنيفات، النسخ الاحتياطي، قراءة ملفات CBZ/CBR، قارئ بالصفحات الأفقية.
* **لا يتجاوز التطبيق حماية المواقع.** عند ظهور تحقق متصفح يعرض ذلك بوضوح ويفتح المتصفح المدمج ليُكمله المستخدم، وتُشارَك الكوكيز بعدها.
* **لم أبنِ محولات خاصة بقائمة مواقع المحتوى الجنسي التي أرسلها المستخدم**، ولم أختبر عليها (قرار مقصود). المحرك العام محايد، والمستخدم هو من يضيف مواقعه.
* `usesCleartextTraffic=true` لأن المستخدم قد يضيف مواقع HTTP فقط. أزله لفرض HTTPS.
* لا صلاحيات تخزين: التنزيلات في مجلد التطبيق الخاص (`getExternalFilesDir`) وهذا كافٍ على كل الإصدارات.
* لم يُولَّد Gradle wrapper (يحتاج شبكة)؛ شغّل `gradle wrapper --gradle-version 8.9`.
